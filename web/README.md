# Web edition: hosting and links

`companions/` holds the static web edition of the companion, with this folder layout:

- `companions/math-machine-intelligence/` is the companion: the library page (`index.html`), 34 chapter pages, and the slider data and pictures under each chapter's `states/` folder.
- `companions/_shared/` holds the two stylesheets every page uses (`companion.css` and `publishing-frame.css`). Keep it beside `math-machine-intelligence/`, or the pages lose their styling.

To use it offline, open `companions/math-machine-intelligence/index.html` in a browser. To host it, copy the whole `companions/` folder to any static web host.
